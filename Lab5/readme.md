# Лабораторна робота №5
## Мета лабораторної роботи: 
Засвоєння теоретичного матеріалу та набуття практичних навичок розв'язання задачі сортування заданої категорії елементів за допомогою різних алгоритмів сортування у двовимірних масивах.

## Постановка задачі:
1. Задано двовимірний масив (матрицю) цілих чисел A[m,n] або A[n,n], де m та n — натуральні числа (константи), що визначають розміри масиву. Виконати сортування цього масиву або заданої за варіантом його частини у заданому порядку заданим алгоритмом (методом). Сортування повинно виконуватися безпосередньо у двовимірному масиві **«на тому ж місці»**, тобто без перезаписування масиву та/або його частини до інших одно- чи двовимірних масивів, а також без використання спискових структур даних.
2. Розміри матриці m та n взяти самостійно в межах від 7 до 10.
3. При тестуванні програми підбирати такі вхідні набори значень матриці, щоб можна було легко відстежити коректність виконання сортування, і щоб ця коректність була протестована для всіх можливих випадків. З метою тестування дозволяється використовувати матриці меншого розміру.

## Варіант 20
Задано квадратний двовимірний масив (матрицю) цілих чисел A[n,n]. Відсортувати побічну діагональ масиву методом вибору за незбільшенням.



## Програмний код
#### (Lab5)
```c
#include <stdio.h>
#define n 8

int main()
{
    int matrix[n][n];
    int lenght = sizeof(matrix[0]) / sizeof(matrix[0][0]) - 1;
    float Temp;

    for (int i = 0; i < lenght + 1; i++)
    {
        printf("Enter the %d value for row #%d of the matrix: ", n, i+1);
        for (int j = 0; j < lenght + 1; j++)
        {
            scanf("%d", &matrix[i][j]);
        }

    }

    printf("\n----------------------------------------\n");
    for (int i = 0; i < lenght+1; i++)
        {
            for (int j = 0; j < lenght+1; j++)
            {
                printf("| %d ", matrix[i][j]);
            }
            printf("\n----------------------------------------\n");
        }


    for (int i = 0; i < lenght; i++)
    {
        
        int cordX = lenght - i, cordY = i;
        for (int j = i+1; j <= lenght; j++)
        {
            
            if (matrix[lenght - j][j] < matrix[cordX][cordY])
            {
                cordX = lenght - j, cordY = j;
            }
            
        }
        
        Temp = matrix[lenght-i][i];
        matrix[lenght-i][i] = matrix[cordX][cordY];
        matrix[cordX][cordY] = Temp;
        
    }
    
    printf("\n----------------------------------------\n");
    for (int i = 0; i < lenght+1; i++)
        {
            for (int j = 0; j < lenght+1; j++)
            {
                printf("| %d ", matrix[i][j]);
            }
            printf("\n----------------------------------------\n");
        }
    return 0;

}
```
